# The Code on Every Bottle Cap

**The find:** Nearly every plastic bottle cap carries a code like "28-410" — the first number is the neck's outer diameter in millimeters, the second encodes thread height — a standard jointly set decades ago by the Glass Packaging Institute and the Society of the Plastics Industry so any manufacturer's cap reliably fits any manufacturer's bottle on filling lines running up to 1,200 bottles a minute.
**The surprise:** A code almost nobody has ever looked at, on an object twisted open thousands of times a year, is a near-century-old interoperability standard that exists purely so machines don't jam.
**The idea:** [Path dependency](../../../concepts/path-dependency.md): when a component must be swappable across competing manufacturers at high machine speed, an old industry-wide numbering code becomes permanent infrastructure, not branding.
