# The default that backfired

**The find:** OECD researchers secretly lowered the default winter thermostat setting in their own office building by 1°C per week. A 1°C default cut reduced the actual chosen temperature by 0.38°C — but cutting the default by 2°C or more triggered employees to notice and manually override it back up, erasing the energy savings entirely.
**The surprise:** The default effect has a ceiling — push the nudge too far and people stop sleepwalking and start actively fighting back, wiping out the gain from going subtle.
**The idea:** The [Default effect](../../../concepts/default-effect.md) only works below a detection threshold; past it, the nudge becomes visible and the boomerang erases the gain.
