# Shopify was a failing snowboard shop

**The find:** Tobi Lütke built the engine behind Shopify in 2004 to sell snowboards online under the name Snowdevil. The store itself never took off — but other merchants kept asking for the software running underneath it.
**The surprise:** A company now worth roughly $150 billion exists because a snowboard store failed and its checkout software didn't.
**The idea:** [Accidental product](../../../concepts/accidental-product.md): the tool built to solve your own narrow problem can end up worth more than the problem ever was.
