# Microsoft's Easter egg alibi

**The find:** Ed Fries, Microsoft's Excel lead in the 1990s, says leadership let programmers bury Easter eggs in shipped code on one condition: no normal code path could trigger the egg, so engineers routed it through an obscure key sequence that corrupted a memory pointer to launch it.
**The surprise:** The rule wasn't creative, it was legal cover — Fries calls it "plausible deniability by management" — so more engineering effort went into disguising how the egg launched than into the egg itself.
**The idea:** none
