# Duolingo's nags decay like memory

**The find:** Duolingo's push-notification system runs a published algorithm, trained on 200 million reminder sends, that deliberately demotes a specific nag message once you've seen it recently — because its persuasive novelty decays over time, the same way memory does.
**The surprise:** The fix isn't a harder guilt-trip. Duolingo turned its own signature teaching tool — the spaced-repetition "forgetting curve" normally used to schedule vocabulary review — back on its own notifications, treating your attention to a message as something that decays and has to be relearned.
**The idea:** [Novelty-decay scheduling](../../../concepts/novelty-decay-scheduling.md) — the same model used to time when a fact needs reviewing can be repurposed to time when a persuasive nudge needs refreshing.
