# The nudge governments avoid using

**The find:** Inside the famous 126-trial, 23-million-person comparison of government nudges versus academic studies, reminders — the lever governments use constantly — averaged a measured 0.29 percentage points, functionally zero. Default-switch interventions, which governments rarely attempt, produced 9.4 and 11.2 percentage point effects, nearly matching academic-sized results.
**The surprise:** The nudge type governments reach for by default is nearly inert at scale; the one they're almost too cautious to use performs like a lab study.
**The idea:** The [Default effect](../../../concepts/default-effect.md) holds up at scale because it doesn't need attention to work — it operates even when people never engage, unlike reminders.
